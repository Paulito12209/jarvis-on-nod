Was ist „Tool Calling“?

Das Gehirn kann nicht selbst ins Internet schauen. Aber es kann Nod bitten, ein Werkzeug zu benutzen.
🙋1. Du fragst
„Wie wird das Wetter morgen in Köln?“
🧠2. Gehirn denkt
„Das weiß ich nicht auswendig. Ich brauche das Werkzeug Websuche.“
🤲3. Nod handelt
Sucht im Internet nach „Wetter Köln morgen“ und gibt das Ergebnis zurück.
💬4. Antwort
„Morgen in Köln: 12 °C und Regen. Nimm einen Schirm mit!“
🔎 Websuche🌐 Webseite lesen📁 Dateien📧 E-Mail📅 Kalender💻 Code ausführen

Der Notizblock („Context length“)

So viel Text kann sich das Gehirn auf einmal merken. Nod braucht einen großen Block!
4k
Standard bei vielen Apps.
Zu klein! Nod passt
nicht mal hinein.
32k
Geht knapp.
Lange Aufgaben werden schwer.
64k ✔
Das brauchst du.
Nods Anleitung nimmt ~20k ein,
der Rest ist für deine Aufgabe.
So stellst du es ein
Ollama-Symbol oben in der Menüleiste
→ Settings
→ Context length
→ Regler auf 64k
